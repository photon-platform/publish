photon_platform.publish.social_capture¶

Local HTML+CSS Social Media Card Capture (1280×640 PNG) via headless Chrome.

Renders the exact same Foundation theme <article class=”card card–social”> markup and compiled CSS as the live website, then snaps a crisp 1280×640 PNG using the locally installed Chrome/Chromium binary (–headless=new –screenshot).

This runs ONLY when invoked locally via publish social-banner (never during publish build or GitHub Actions).
