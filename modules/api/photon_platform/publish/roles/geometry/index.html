Parse :g: role content display <target> or bare target into (display, target).

Handles targets that themselves contain angle brackets, such as: - AB <0255.g1:/ A B /> -> ("AB", "0255.g1:/ A B /") - ABC <0255.g1:< A B C >> -> ("ABC", "0255.g1:< A B C >") - A <0309.g1:< K A G )> -> ("A", "0309.g1:< K A G )") - 0255.g1:/ A B / -> ("AB", "0255.g1:/ A B /")

Parse :eq: role content display <spec> into (display, spec).

Handles specs that themselves contain angle brackets (such as < A B C >), e.g.: - equal <0255.g1:[ A C ] = 0255.g1:[ A B ]> -> ("equal", "0255.g1:[ A C ] = 0255.g1:[ A B ]") - equal <0265.g1:< A B C > = 0265.g1:< A C B >> -> ("equal", "0265.g1:< A B C > = 0265.g1:< A C B >")
