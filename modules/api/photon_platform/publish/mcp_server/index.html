photon_platform.publish.mcp_server¶

Zero-dependency MCP stdio server for photon-platform/publish (publish mcp).

Supports both Content-Length framed and newline-delimited JSON-RPC 2.0 over stdio on Python 3.13, keeping Sphinx and extensions warm in-process while returning compact, noise-free JSON summaries for incremental HTML builds, batch builds, EPUB 3 builds, and primary-source folio link audits.
