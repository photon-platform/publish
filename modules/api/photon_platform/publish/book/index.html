photon_platform.publish.book.detect_companion_tracks(env: Any, pagename: str) → List[Dict[str, Any]]¶

Detect companion tracks for pagename in env.found_docs.

Supports:

  • Elements 2.0 tracks: index (Pseudocode), video (Video), code (Code), heath (Heath)

  • Euclid tracks: index / proposition, commentary, notes, folio or <pagename>.commentary, <pagename>.notes

  • Multilingual tracks: <stem>_en / -en, -el (Greek), -la (Latin), -de (German), -fr (French), -it (Italian), -da (Danish), -summary, -notes

  • Hoenen tracks: <stem> (Latin), <stem>-en, <stem>-summary, translation-notes-<stem>

Automatically register bare sibling companion tracks into a hidden toctree on book index.rst files.

Eliminates manual hidden .. toctree:: boilerplate for la.rst, el.rst, de.rst, fr.rst, it.rst, da.rst, summary.rst, notes.rst, commentary.rst, folio.rst, and title-<lang>.rst files inside :layout: book directories.
