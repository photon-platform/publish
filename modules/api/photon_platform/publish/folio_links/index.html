photon_platform.publish.folio_links.resolve_folio_url(env: Any, current_docname: str, folio_id: str, project_root: pathlib.Path | None = None) → str | None¶

Resolve folio_id to a verified primary-source scan or text-locus URL.

Resolution order: 1. Non-gitignored 4-digit .png or .jpg scan in resources/ -> GitHub raw URL (or folio_base_url). 2. Track-aware resources/**/folio_map.json entry -> GitHub blob/…#L<line> or external facsimile URL.
