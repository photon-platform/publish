photon_platform.publish.folio_review¶

Folio Review & Vetting Web Application for PHOTON Publish.

Provides an interactive local web interface (publish folio) to inspect folio scans, read and edit side-by-side RST/Markdown transcriptions and notes, verify graphic bounding boxes on full-page scans, and track folio-by-folio vetting status exclusively within a repository’s resources/ directory.
